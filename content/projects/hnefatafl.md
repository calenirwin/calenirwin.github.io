Hnefatafl, sometimes called Viking chess, is the setting for this board-game and reinforcement-learning project. It began as coursework for CISC-856 at Queen's University in winter 2021.

## Exploring learning through games

The project brings a board game and reinforcement learning together in a Python notebook workflow. The original repository includes the game implementation, training code, notebooks, and saved model weights.

## Explore the original project

The [source repository](https://github.com/calenirwin/gym-hnef) contains the implementation and setup instructions. Its original entry point is `run.ipynb`, intended to be opened on a cloud notebook platform such as Google Colab. This portfolio page describes the project; there is no browser-playable demo here yet.
